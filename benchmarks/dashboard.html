🏗️ Architecture

Retrieval Pipeline

1 Query → FTS (PostgreSQL ts_rank) + Vector (Qdrant cosine)
2 Hybrid scoring: FTS×3.0 + Vector×1.1 + Structured + Importance + Temporal
3 Cross-encoder re-ranking (ms-marco-MiniLM-L-6-v2)
4 Post-retrieval DB status filter (superseded/deleted removal)
5 Feedback boost + entity/property structured bonus

Key Innovations

🕐 Relative Temporal Ranking — ROW_NUMBER within entity+property partition, not absolute NOW() distance
🔍 Hybrid SQL Push-down — Metadata filters in SQL WHERE, not post-filter on top-50
⚡ Cached Cross-Encoder — Module-level singleton avoids 52× latency penalty
🗑️ Post-Retrieval Status Check — Qdrant vectors lack status; DB re-verification catches superseded items
📐 Dual-Level NLI — Sentence + paragraph scoring prevents false contradiction from paraphrase fragments
