📥 Ingestion

  • Tracked Path Watcher inotify-based file monitoring
  • Heartbeat Worker periodic checkpoint creation
  • Transcript Dehydrator session log → memory chunks

💾 Storage

  • PostgreSQL 18,686 items + pgvector + FTS
  • Qdrant 2 collections (memory + code)
  • Neo4j knowledge graph + code graph

🔍 Retrieval

  • Hybrid Search vector + FTS + Qdrant fusion
  • Context Hydrator unified code+memory+graph
  • Cross-Encoder reranking for precision

🔗 Zero-Reread Code Engine

8-slice architecture: AST parsing (Python + C++ via tree-sitter) → embedding into Qdrant → Neo4j graph (IMPORTS, CALLS, DEFINES, HAS_METHOD, ABOUT_CODE) → context hydration with token-optimized output. File watcher integration for live updates in ~5s.

🎮 70-Level Orchestrator

Enterprise game studio pipeline: Conductor (10-phase governor) → multi-model execution bridge (Opus/GPT/Gemini) → UE5 code generation → art generation (gpt-image-1) → QA automation → platform certification → LiveOps → economy simulation → legal compliance. 4,300+ tests.
