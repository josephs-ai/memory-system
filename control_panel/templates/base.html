🏗️ Retrieval Pipeline

Pipeline Stages

1 Query → FTS (PostgreSQL ts_rank) + Vector (Qdrant cosine)
2 Hybrid: FTS×3.0 + Vector×1.1 + Structured + Importance + Temporal
3 Cross-encoder re-ranking (ms-marco-MiniLM-L-6-v2)
4 Post-retrieval DB status filter
5 Feedback boost + entity/property bonus

Key Innovations

🕐 Relative Temporal Ranking — ROW_NUMBER within entity+property partition
🔍 Hybrid SQL Push-down — Metadata filters in WHERE, not post-filter
⚡ Cached Cross-Encoder — Singleton avoids 52× latency penalty
🗑️ Status Check — DB re-verification for Qdrant superseded items
📐 Dual-Level NLI — Sentence + paragraph for fact verification
